# visit-check

하나은행 방문관리 체크표 — 모바일 웹앱의 **화면(index.html)** 만 담은 저장소입니다.

- 주소: https://p71021jw.github.io/visit-check/
- 데이터는 이 저장소에 없습니다. 화면이 Google Apps Script 웹앱의 JSON API(`?api=1`)를 호출해
  스프레드시트를 읽고, 체크·메모를 다시 씁니다. (비밀번호가 맞아야 응답합니다.)
- 첫 접속 시 비밀번호를 한 번 입력하면 그 기기(브라우저)에 저장되어 다음부터는 바로 열립니다.
  화면 아래 **🔒 잠금**을 누르면 저장된 비밀번호를 지우고 다시 입력할 수 있습니다.
- 바로 열기: `?week=1` ~ `?week=4` (주차), `?view=map` (지도) — 예) `.../visit-check/?week=2&view=map`
- **지도 탭**은 열려 있는 동안 브라우저 위치(`navigator.geolocation.watchPosition`)로 현재 위치를
  파란 점(펄스)으로 함께 보여 줍니다. 오른쪽 아래 **내 위치** 버튼을 누르면 그 자리로 이동하고,
  위치 권한이 없으면 그때 요청합니다. 탭을 벗어나면 추적을 멈춥니다(배터리).
  처음 한 번은 브라우저가 위치 권한을 묻습니다.

## 고치기

`index.html`을 고쳐 이 저장소의 `main` 브랜치에 올리면 1~2분 뒤 GitHub Pages에 반영됩니다.

## 참고

- 지도(카카오맵)는 카카오 개발자 콘솔의 **플랫폼 → Web → JavaScript SDK 도메인**에
  `https://p71021jw.github.io` 가 등록되어 있어야 표시됩니다. 등록 전에는 목록·체크·메모만 동작합니다.
- 스프레드시트 쪽 API 코드는 Apps Script 프로젝트에 별도로 들어가 있습니다.
